# ADR 0002 — Config and data live together under `~/.pi/agent/tool-manager/`

- 状态：已采纳
- 日期：2026-11-11

## 背景

Tool Manager 有两种状态：

- **配置**：被禁用的工具名（`{"disabledTools": [...]}`），人可读、可手改、必须跟着用户走。
- **用量数据**：一台设备一个 JSONL 文件，只由扩展写入，可能来自多台机器。

改造前配置是 `~/.pi/agent/tool-manager.json`，直接躺在 `~/.pi/agent/` 下——该目录已经有几十个扩展的文件，容易看漏，也难以一眼判断哪些文件属于同一个扩展。

## 决定

```
~/.pi/agent/tool-manager/
├── tool-manager.json          # 配置：禁用工具名
└── data/
    └── usage-<设备名>.jsonl    # 总量数据：按设备分区
```

- 配置与数据分家：配置是「意图」，数据是「事实」，备份/清理策略不同。
- 老文件 `~/.pi/agent/tool-manager.json` 在 `session_start` 时**一次性迁移**到新位置，迁移成功后删除老文件；新文件已存在时不动它。
- 迁移只做一次、只判存在性，不做内容合并——两份内容同时存在时无法自动判断谁更新。

## 后果

- 删除整个目录 = 同时丢弃配置与历史，意图明确。
- 迁移失败（权限、只读盘）时功能退化为「没有全局配置」，不影响会话级配置；老文件原样保留。
